# Mercado Digital Papantla

## Nombre y descripción del proyecto
**Mercado Digital Papantla** es una plataforma web de comercio electrónico enfocada en la venta, difusión y comercialización de productos artesanales y culturales locales del municipio de Papantla. Su propósito es conectar directamente a los productores y artesanos locales con un mercado más amplio mediante un entorno digital accesible.

## Objetivo general y principales funcionalidades
**Objetivo general:** 
Desarrollar una plataforma web para la comercialización de productos artesanales de Papantla.

**Principales funcionalidades:**
* Registro y administración de perfiles para artesanos locales.
* Catálogo digital interactivo de productos con fotografías, precios y descripciones.
* Motor de búsqueda y filtrado por categorías (ropa tradicional, gastronomía, artesanías, etc.).
* Enlaces de comunicación directa (mensajería) entre los clientes y los vendedores.

## Tecnologías, herramientas y dependencias utilizadas
* **Backend:** Python
* **Frontend:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git y GitHub
* **Entorno:** Entornos virtuales de Python (`venv`)

## Requisitos de hardware y software
**Requisitos de Hardware:**
* Computadora con al menos 4 GB de memoria RAM.
* Conexión estable a internet.

**Requisitos de Software:**
* Sistema Operativo Windows, macOS o Linux.
* Python 3.8 o una versión superior instalada.
* Un navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge).
* Git instalado en el sistema.
